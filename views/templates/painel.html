API de envio

Use este token no seu sistema para enviar mensagens e imagens pelo seu WhatsApp. Guarde-o como uma senha — quem tem o token envia pelo seu número.

Gerar um token novo invalida o atual na hora — atualize seu sistema antes. 
curl -X POST {{ base_api }}/api/v1/mensagem \
  -H "Authorization: Bearer SEU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"numero":"5544999998888","mensagem":"Seu pedido saiu para entrega!"}'
Responde 202 na hora com um id_envio. A mensagem sai em seguida, com “digitando…” proporcional ao texto — de 15 a 40 segundos. Consulte o resultado em GET /api/v1/envio/<id_envio>. 
curl -X POST {{ base_api }}/api/v1/imagem \
  -H "Authorization: Bearer SEU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"numero":"5544999998888","imagem":"https://.../foto.jpg","legenda":"Chegou!"}'
imagem aceita URL pública ou base64. Para enviar sem a espera da digitação, acrescente "typing": false.
